# 迎撃海域

遊ぶ: https://geigeki-kaiiki.masseater.dev/

3D俯瞰のリアルタイム海戦ゲーム。自艦1隻で三波に分かれて来る敵艦隊と超兵器を沈める。

```sh
pnpm install
pnpm dev            # 遊ぶ
pnpm check          # 型・テスト・ビルド
pnpm balance        # ボット対戦で難易度を確認
pnpm build:artifact # 1枚のHTMLに書き出す
```

操作は W/S で機関、A/D で舵、左クリックで主砲、右クリックで捕捉、Tab で目標切り替え、F で魚雷、R で応急修理、ホイールで視点の遠近。
